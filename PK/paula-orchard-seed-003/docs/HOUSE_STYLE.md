# House Style — Biblical Street Drama

Use this as a consistent visual constitution, not as an instruction to imitate one existing film.

## Core look

- biblical-period street-drama world
- tactile stone, wood, dust, cloth, clay, smoke, sunlight, lamplight
- emotionally modern performances inside historically textured environments
- dramatic faces and readable body language
- occasional comic swagger without mocking sincere spiritual stakes
- ordinary people framed with mythic seriousness
- strong silhouettes and simple compositions that survive vertical cropping

## Camera language

- close faces for accusation, hesitation, longing, recognition
- low, slow push-ins for revelation
- lateral street movement for gossip, pursuit, social pressure
- still tableau for judgment/choice
- hands and objects as emotional inserts
- wide vertical architecture when the person should feel small against the world

## Symbol vocabulary

Use only when earned by the story:

- door / gate — decision, access, exclusion, return
- lamp / flame — attention, waiting, witness
- water / vessel — need, offering, change, abundance
- dust — consequence, travel, humility, residue
- bread / table — provision, status, belonging, conflict
- cloth / garment — identity, concealment, social role
- coin / weight — value, debt, choice
- road — departure, pursuit, return

The symbol should remain a visual affordance, not a forced interpretation.
