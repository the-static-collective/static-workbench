# Architecture Receipt

This workbench is a deliberately small derivative pattern, not a fork of every Static Collective system.

## MEMENTO seam used

Inspected `the-static-collective/MEMENTO` main and its documented membrane:

```text
source -> encounter -> interpretation -> proposal -> ADMIT/REFUSE/FOG -> ledger
```

For Paula's creative desk, that compresses to:

```text
raw trace -> candidate kernels -> KEEP/HOLD -> creative continuation
```

The important inherited distinction is that source material and generated narrative are not the same thing.

## MEMENTO seam intentionally omitted

The workbench does not need world registries, cross-world edge receipts, observer-cut projection machinery, PostHog, or full ledger constitution for the first use case.

## Haunted Toaster seam used

Inspected `the-static-collective/the-haunted-toaster` after the BETA 0.0.0 reconciliation. The useful product law is the separation between machine-generated possibility and human continuation authority.

The story workbench adapts that as:

```text
KERNELS = possibilities
KEEP = continuation permission
```

It does not import the Toaster's rendering genome. The first assembly uses Flow Scenebuilder; a Toaster mod can come later when actual scene-assembly requirements are witnessed.
