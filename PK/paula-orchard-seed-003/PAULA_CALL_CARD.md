# Paula Call Card

Open `START_PAULA.bat`.

Then the whole loop is:

```text
TELL IT
  Paula speaks/types freely

HARVEST
  click Save + Build ChatGPT Packet
  paste into Paula's dedicated ChatGPT Project

CHOOSE
  Paula says KEEP K1 / K2 / K3, or asks for alternate kernels

MAKE IT FILMABLE
  FRAME IT. BOARD IT. FLOW IT. Return STORY_CARD_JSON.

SAVE
  paste JSON back into the Story Desk

GENERATE
  click Build Flow Batch
  make HERO / BRIDGE / TEXTURE shots in Flow

ASSEMBLE
  use Flow Scenebuilder first
```

Do not explain MEMENTO, receipts, or architecture unless Paula asks. The UX is simply: **tell story -> choose story -> make shots.**

For a new GitHub repo, double-click `BOOTSTRAP_GIT.bat` after creating the empty repository and paste its URL when asked.
