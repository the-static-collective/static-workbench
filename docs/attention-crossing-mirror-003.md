# ATTENTION-CROSSING-MIRROR-003

Experimental integration carrier, stacked on the open MIRROR-001 / HOUSE branch.
Copies the existing ATTENTION-CROSSING-001 local bar and SQLite declaration
module, then mounts the bar in the MIRROR inspector **only after a human clicks
the code-owned demo card**. Target: mirror-fixture / mirror-001:demo-card.
No arbitrary iframe DOM, external app target, CSS source edit, or project-level
authority is inferred from this mark.

Clicking Joyful, Useful, Curiouser, or None writes only a Workbench-local human
declaration; MIRROR's own explicit preview and apply buttons remain distinct.
The test checks that a value mark leaves the fixture's source SHA-256 unchanged.
The mirrored bar is an integration copy: PR #32/#35 own the shared upstream
implementation, and this carrier must be reconciled/deduplicated against those
branches before promotion. This branch is **not** a claim that any of these
upstream PRs have merged. The Linux browser selection/restart smoke and
cross-branch integration checks must be performed before promoting the draft.
