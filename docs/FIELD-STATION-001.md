# FIELD-STATION-001 — The Radio Becomes a Compositional Center

## Claim

The House can compose a small read-only field of nearby possibilities from already-witnessed local state without ranking, selecting, executing, or inventing availability.

House receipts + audio/radio witnesses + Static Live reachability + Lifestream moment inbox + repository presence → FIELD STATION → 3–6 nearby doors → nothing.

The final arrow is deliberate. The Field Station only shows what is nearby.

RECOMMENDATION != SELECTION
DOOR != CROSSING
AVAILABILITY != OBLIGATION
FIELD STATE != WORLD STATE
READ != OCCURRENCE

## One earned radio aperture

The radio lane exposes only the next currently earned aperture for the newest exact audio specimen:

- no window → Cut one bounded audio window
- window, no pair → Prepare two isolated first-listen booths
- pair, fewer than 2 sealed listens → Invite both fresh listeners independently
- 2 sealed listens, no dialogue → Let them compare notes
- sealed dialogue, no episode for this pair → Assemble a playable radio episode
- episode for this pair → Play the assembled episode

A newer audio window immediately becomes the current specimen. An older pair cannot continue advancing merely because it is the latest pair globally.

NEW WINDOW != OLD PAIR CONTINUATION

Previous windows, pairs, listens, dialogues, and episodes remain historical witnesses.

## Live lane

Static Live remains its own authority. A static-live checkout existing is not the same as the broadcast service being reachable.

If an episode exists and a Static Live checkout is present, the field may surface **Offer the episode to Static Live**. The door evidence states whether the local service is actually reachable.

The Field Station never reports a checkout as a live occurrence.

## Present-occurrence lane

If Lifestream has a registered moment, the newest one may appear as **Open the newest preserved live moment**. The field carries the inbox status exactly; registered_not_currently_reverified is not silently upgraded into a current verified occurrence.

## House lane

The field may surface one already-open, uncrossed House proposal. It does not select it or create a duplicate door; it points back to the durable House door id and original adapter hint.

## Silence lane

Every field contains **Hold silence**. This is not a fallback error state.

NOTHING NEEDS TO HAPPEN BECAUSE SOMETHING COULD HAPPEN

## Inspectable memory pressure

FIELD-STATION-001 has no learned taste model and no numerical preference score. Its first memory-pressure projection consists only of explicit witnessed counters/rules, currently including unresolved House doors, registered live moments, and absence of a first assembled episode.

MEMORY PRESSURE != AUTHORITY
COUNT != VALUE
FREQUENCY != PREFERENCE

## What v0 refuses to pretend exists

The conceptual Field Station eventually wants bounded Autodiscography historical neighbors, Haunted Phonograph musical answers, Haunted Toaster visual companions, Daily Slice spoken interstitials, Dogram perturbations, and 3rdi availability witnesses.

FIELD-STATION-001 does not generate those from repository presence alone. A checkout proves only that code is locally present. A bounded query/capability aperture must make the claimed action actually available and attributable first.

REPOSITORY PRESENT != CAPABILITY AVAILABLE
CONCEPTUAL ORGAN != OPEN DOOR

## Field state identity

The read-only projection receives a deterministic content identity: field-station-v0:<sha256>. Repeated reads over unchanged inputs return the same identity. Reading the field creates no House receipt and does not change world version.

## House surface

The Field Station appears above the Mail Table. It shows PRESENT, the current playable artifact when one exists, explicit memory-pressure chips, and 3–6 nearby door cards. Each card exposes its reason, evidence, target, and laws.

There are deliberately no Select or Cross buttons on Field doors. The existing House remains the place where selection and crossing occur.

## First compositional consequence

This makes the radio a center without making it a master application. Additional organs enter by adding lawful apertures, not by being absorbed into one ontology.

That is the compositional center:
