# HOUSE-REMEMBERS-DOORS-004 — Creative Return Loop

## Claim

The House can now move one local crossing through distinct organs without collapsing their authority:

```text
DoorHouse local crossing
  → reLATTE RECEIVE → HOLD
  → GHoT body offer
  → explicit human body choice
  → Haunted Toaster witness-sigil projection
  → GHoT execution receipt
  → artifact bytes return home
  → new sealed House letter
  → Autodisco isolated First Encounter
  → packet-only OR real sealed first response
  → new sealed House letter
```

## Creative instrument

The first instrument is deliberately small:

`creative.toaster.witness-sigil`

It feeds the SHA-256 digest of the local House artifact into Haunted Toaster's existing deterministic `witness-sigil/v0.1` projection.

The selected GHoT body executes Toaster-owned code. GHoT does not duplicate the sigil grammar.

The adapter returns:

- SVG bytes + digest;
- recipe bytes + digest;
- Toaster receipt bytes + digest.

The executing body also writes its local copies. The House uses the returned bytes so a remote body can still return an artifact without pretending its filesystem is shared.

## First encounter

The returned SVG may be sent to Autodisco First Encounter.

The packet accepts only the exact SVG artifact. It refuses hidden history fields.

If a real Gemini listener is available, the first response is sealed before dialogue.

If no real listener is available:

```text
status = packet-only
response = null
```

The House then records an unanswered packet. It does not manufacture a DJ response.

## Memory split

The House stores these as separate witnesses:

- `relatte`
- `ghot_offer:<offer_id>`
- `ghot_execution`
- `autodisco_packet`
- `autodisco_first_response` when one really exists

A packet may therefore survive unanswered and later receive a real first response without rewriting the earlier silence.

## What is now genuinely closed

A human choice can produce a local occurrence, cross a generic substrate, acquire an explicitly selected execution body, become a real visual artifact, return with receipts, and create a new reachable future in the House.

When a real isolated listener is configured, the artifact also produces a sealed fresh response that becomes another new House letter.

This is the first bounded implementation of:

```text
dream → choice → crossing → body → artifact → witness → fresh encounter → new dream
```
