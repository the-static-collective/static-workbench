# HOUSE-REMEMBERS-DOORS-001

## Claim

This slice proves one complete **Workbench-local** loop:

```text
sealed letter
  -> explicit opening
  -> proposed doors
  -> human selection
  -> explicit crossing
  -> real local transformation
  -> agency receipt
  -> world version increments
  -> new sealed letter appears
```

It does **not** prove external execution through reLATTE, GHoT, TranchNode, Autodisco, LOVE, Dogram, or Haunted Toaster.

## Why this slice

The surrounding projects now share a useful grammar:

- proposal is not selection;
- selection is not crossing;
- capability is not authority;
- memory may inform without deciding;
- a crossing may create a new place or reachable future without rewriting the past.

The smallest honest implementation should therefore make those states visible before it connects more organs.

## Agency receipt

The receipt preserves:

1. source letter digest;
2. exact proposed door digest;
3. declared perturbation;
4. local human selection authority;
5. execution body and mode;
6. artifact digest;
7. adapter truth;
8. world before and after.

The receipt is evidence of this local occurrence. It is not a donor-native receipt for any external organ.
